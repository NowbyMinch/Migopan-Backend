# Migopan - Software de Rotina Gamificado 

An application/website built to help user productivity in their daily activities through gamification principles, encouraging routine organization by linking it to the well-being of a virtual pet.

[Português] | [English]

---

## 📌 Sobre o Projeto

A desorganização da rotina gera ineficiência e frustração, muitas vezes resultando em procrastinação e abandono de metas. O **Migopan** propõe solucionar esse problema unindo o gerenciamento de tarefas ao cuidado de um mascote virtual (inspirado nos clássicos *Tamagotchi*), utilizando dinâmicas de engajamento consagradas no mercado como as de *Duolingo* (ofensivas, metas diárias) e a flexibilidade visual do *Trello*.

O nome origina-se da fusão de:
* **Mi:** Arroz (Chinês)
* **Go:** De *Gohan*, Arroz (Japonês)
* **Pan:** Abreviação de Panda

O coração do software é o **Migo**, um panda vermelho customizável que reflete a produtividade do mundo real na saúde do ecossistema virtual do usuário.

## 🎯 Objetivos

### Objetivo Geral
Auxiliar o desenvolvimento de atividades diárias e a produtividade do usuário de forma lúdica, estimulando-o a cumprir cronogramas para manter o seu mascote virtual saudável e evoluindo.

### Objetivos Específicos
1.  **Mascote Virtual:** Sistema de *Pet Care* em que negligenciar obrigações diárias prejudica a saúde do Migo, enquanto pontos adquiridos compram customizações (roupas, cenários, pelagens).
2.  **Recompensas Gamificadas:** Sistema de moedas (*Bambus Dourados*) e marcos de consistência (*Torre de Bolinhos de Arroz*, que desmorona caso a meta diária de 60% das tarefas não seja batida).
3.  **Gerenciamento Flexível:** Mecanismo avançado de criação, edição e visualização de tarefas com repetições e horários.
4.  **Monitoramento Ativo:** Validação de tarefas via APIs externas (como verificação de geolocalização ou tempo de foco).
5.  **Módulo Social:** Criação de "Famílias de Migos" para gerenciar e distribuir tarefas domésticas ou dinâmicas corporativas corporativas em equipes.

## 🛠️ Tecnologias e Ferramentas

O projeto foi planejado utilizando tecnologias modernas para escalabilidade e performance cross-platform:

| Camada | Tecnologia | Descrição |
| :--- | :--- | :--- |
| **Frontend** | HTML5 / CSS3 / JavaScript | Estrutura semântica e estilização responsiva com suporte a Bootstrap. |
| **Mobile** | PWA (Progressive Web App) | Conversão da experiência web nativa para funcionamento mobile offline. |
| **Backend** | Java (Spring Boot) / Node.js | API RESTful responsável pelo gerenciamento de regras de negócio. |
| **Banco de Dados** | PostgreSQL | Armazenamento relacional e consistente dos dados de usuários e tarefas. |
| **Design** | Figma | Prototipação de interface (UI) e experiência do usuário (UX). |
